AI Sales Coach - Testing API

API endpoints for AI testing models to interact with the application

Testing Endpoints

These endpoints allow AI testing models to simulate user interactions and validate app behavior.

Get Current State

GET /api/test/state

Returns the current user progress and app state for analysis.

Response: 
{
  "userProgress": {
    "usage_minutes": 15,
    "completedModules": ["closing-fundamentals"],
    "rolePlaySessions": 3,
    "averageScore": 85,
    "subscription_status": "trial"
  },
  "timestamp": "2024-01-01T12:00:00Z"
}

Simulate Usage

POST /api/test/simulate-usage

Simulates user time spent in the application.

Body: 
{ "minutes": 15 }

Add Role-Play Session

POST /api/test/add-roleplay

Simulates completing a role-play session with a score.

Body: 
{ "score": 85 }

Complete Module

POST /api/test/complete-module

Simulates completing a training module.

Body: 
{ "moduleId": "closing-fundamentals" }

Reset Progress

POST /api/test/reset

Resets all user progress to initial state.

Generate Test Data

POST /api/test/generate-data

Generates realistic test data for various user scenarios.

Body: 
{ "scenario": "returning_user" }
Scenarios: new_user, returning_user, premium_user

Validation Endpoints

Validate Subscription Flow

GET /api/test/validate-subscription

Tests if subscription modal appears when usage limit is reached.

Validate Training Progression

GET /api/test/validate-training

Tests if training modules unlock in proper sequence.

JavaScript Testing Interface

For direct browser testing, these functions are available in the console:

// Access the testing helper const helper = window.AITestingHelper.getInstance(); // Simulate different user journeys await helper.simulateUserJourney('new_user'); await helper.simulateUserJourney('returning_user'); await helper.simulateUserJourney('premium_user'); // Generate test data const testData = helper.generateTestData('moderate'); // Validate app state const isValid = helper.validateAppState({ usage_minutes: 15, subscription_status: 'trial' }); // Test specific flows const subscriptionWorks = await helper.testSubscriptionFlow(); const trainingWorks = await helper.testTrainingProgression(); // Export state for AI analysis const currentState = helper.exportStateForAI();
